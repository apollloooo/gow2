GET THE APK WITH GITHUB (no installs, works from a phone browser)
1. Make a free account at github.com and tap New repository (any name).
2. Tap "uploading an existing file". Upload ALL the contents of this folder,
   including the hidden .github folder (on a PC, drag the folder contents in).
   Tap Commit changes.
3. Open the Actions tab. "Build APK" starts by itself (takes ~3 minutes).
4. Open the finished run, scroll to Artifacts, download GodOfWar2Launcher-apk.
5. Unzip it and install app-debug.apk on your phone (allow unknown apps).

CUSTOM BUTTONS
On the Play screen, use "My buttons" to add a button with a name, an app
package name, and an optional game file/link. Tapping it opens that app.
